# 996 Tokens 充值与加赠规则

目标：减少异常注册，鼓励真实用户完成首充并尽快跑通 API Key。

## 规则

| 场景 | 奖励 | 说明 |
| --- | ---: | --- |
| 新用户注册 | $0 | 注册后需要充值才可获得可用额度 |
| 首笔充值 / 月卡 | +$1 | 支付成功后自动加赠，每个账户仅限一次 |
| 后续充值 / 月卡 | 按实到账 | 不重复发放首充奖励 |

## 充值阶梯

| 档位 | 用户支付 | 到账/权益 | 定位 |
| --- | ---: | ---: | --- |
| 注册账户 | $0 | $0 | 先创建账户和 API Key |
| 试用月卡 | $1 | $1 美元额度 | 验证支付和接入 |
| 入门月卡 | $3 | $3 美元额度 | 轻度 Cursor / Claude Code |
| 开发者月卡 | $5 | $5 美元额度 | 日常 AI 编程 |
| 专业月卡 | $10 | $10 美元额度 | 高频调用 |
| 工作室月卡 | $20 | $20 美元额度 | 多工具和多 Key 使用 |
| 团队月卡 | $30 | $30 美元额度 | 团队协作 |

## 对外展示口径

- 注册不直接赠送额度。
- 新用户首笔充值或购买月卡后自动加赠 $1。
- 余额按美元展示，人民币只用于支付结算。
- 如遇充值异常，请联系管理员处理。
