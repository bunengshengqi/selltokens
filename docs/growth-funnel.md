# 996 Tokens 变现漏斗方案

目标：不再用“注册即送”吸引爬虫，改成“真实支付后加赠”，先提升首充质量，再做邀请裂变。

## 1. 注册与加赠

第一版规则：

| 场景 | 奖励 | 说明 |
| --- | ---: | --- |
| 新用户注册 | ¥0 | 注册本身不发额度，避免批量账号直接薅羊毛 |
| 充值 / 月卡 < ¥100 | +¥5 | 支付成功后自动发放 |
| 充值 / 月卡 >= ¥100 | +¥10 | 固定加赠，不做高比例折扣 |
| 邀请奖励 | 绑定首充 | 第二阶段再接首充返佣，未首充不发奖励 |

NewAPI 内部额度换算：

- 当前配置 `QuotaPerUnit=500000`。
- ¥1 等值额度 = `500000` NewAPI quota。
- ¥5 = `2500000` quota。
- ¥10 = `5000000` quota。

## 2. 充值阶梯

按量充值用于补余额，月卡用于提高复购。充值和月卡使用同一套加赠规则。

| 档位 | 用户支付 | 到账/权益 | 定位 |
| --- | ---: | ---: | --- |
| 注册账户 | ¥0 | ¥0 | 无免费额度，先挡住爬虫注册 |
| 小额充值 | ¥10 | ¥15 等值额度 | 验证支付和 API Key |
| 入门月卡 | ¥29/月 | ¥34 等值额度 | 小白转化主推 |
| 开发者月卡 | ¥69/月 | ¥74 等值额度 | 日常 Cursor / Claude Code |
| 专业月卡 | ¥129/月 | ¥139 等值额度 | 高频调用和长上下文调试 |
| 团队月卡 | ¥299/月 | ¥309 等值额度 | 工作室、小团队、优先支持 |
| 大额充值 | ¥500 | ¥510 等值额度 | 熟客/团队，建议人工风控 |

建议：

- 支付方式第一版保持微信支付，不修改支付通道。
- 兑换码和人工补单继续保留，方便处理异常订单。
- 加赠是固定金额，不按比例无限扩大，避免早期毛利失控。

## 3. 首发模型

第一版只开放 7 个模型，后续再扩展：

| 模型 | 加价策略 |
| --- | --- |
| `claude-opus-4-7` | 上游成本 × 1.6 |
| `claude-sonnet-4-6` | 上游成本 × 1.35 |
| `claude-haiku-4-5` | 上游成本 × 1.3 |
| `gpt-5.5` | 上游成本 × 1.5 |
| `gpt-5.4` | 上游成本 × 1.35 |
| `gpt-5.4-mini` | 上游成本 × 1.3 |
| `gemini-3.5-flash` | 上游成本 × 1.3 |

## 4. 上线顺序

1. 关闭 NewAPI `QuotaForNewUser`、`QuotaForInvitee`、`QuotaForInviter`。
2. 将渠道模型列表收敛到 7 个首发模型。
3. 设置 `ModelRatio` 和 `CompletionRatio`。
4. 对已支付的充值订单和月卡订单自动发放加赠。
5. 观察 3-7 天注册、首充、调用成本和异常账号。
6. 第二阶段再开发首充返佣和邀请佣金。
