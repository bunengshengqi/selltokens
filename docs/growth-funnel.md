# 996 Tokens 变现漏斗方案

目标：先降低注册流失，再提高充值转化，最后用邀请系统做低成本获客。

## 1. 免费额度

第一版建议：

| 场景 | 奖励 | 说明 |
| --- | --- | --- |
| 新用户注册 | ¥5 等值体验额度 | 注册后立即到账，降低首次体验门槛 |
| 被邀请注册 | 额外 ¥3 等值体验额度 | 被邀请人总体验额度为 ¥8 |
| 邀请人奖励 | ¥5 等值额度 | 第一版用固定额度快速上线 |

注意：

- 免费额度优先引导用户体验 DeepSeek、Qwen、豆包等低成本模型。
- Claude、GPT、Gemini 最新模型不建议放进免费包，避免被薅羊毛。
- 第二阶段再做每日签到额度，避免早期风控压力过大。

NewAPI 内部额度换算：

- 当前配置 `QuotaPerUnit=500000`。
- 因此 ¥1 等值额度 = `500000` NewAPI quota。
- ¥5 = `2500000` quota。
- ¥3 = `1500000` quota。

## 2. 充值阶梯

按量充值用于补余额，月卡用于提高复购。

| 档位 | 用户支付 | 到账/权益 | 定位 |
| --- | ---: | ---: | --- |
| 免费体验 | ¥0 | ¥5 体验额度 | 注册即送，低成本模型优先 |
| 小额充值 | ¥10 | ¥10 到账 | 验证支付和 API Key |
| 入门月卡 | ¥29/月 | ¥35 等值额度 | 小白转化主推 |
| 开发者月卡 | ¥69/月 | ¥90 等值额度 | 日常 Cursor / Claude Code |
| 专业月卡 | ¥129/月 | ¥180 等值额度 | 高频调用和长上下文调试 |
| 团队月卡 | ¥299/月 | ¥450 等值额度 | 工作室、小团队、优先支持 |
| 大额充值 | ¥500 | ¥625 等值额度 | 熟客/团队，建议人工风控 |

建议：

- 支付方式第一版保持微信支付，不修改支付通道。
- 兑换码和人工补单继续保留，方便处理异常订单。
- 大额充值折扣不要过早公开给所有用户，避免早期成本不可控。

## 3. 邀请系统

第一版：

- 被邀请人：基础 ¥5 + 邀请额外 ¥3。
- 邀请人：成功邀请注册后得 ¥5。
- 风控：同设备、同 IP、异常邮箱批量注册不发放奖励。

第二阶段：

- 接订单回调后做首充返佣。
- 建议首充返佣比例为 15%。
- 每个被邀请人返佣上限 ¥50。
- 退款、补单、异常订单不计佣金。

## 4. 上线顺序

1. 配置新用户注册赠额。
2. 配置邀请人和被邀请人固定额度。
3. 新增月卡套餐。
4. 首页和价格页展示免费试用、月卡和邀请奖励。
5. 观察 3-7 天注册、首充、调用成本和薅羊毛情况。
6. 再开发首充 15% 返佣。
