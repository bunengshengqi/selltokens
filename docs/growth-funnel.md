# 996 Tokens 充值与加赠规则

目标：减少异常注册，鼓励真实用户完成首充并尽快跑通 API Key。

## 规则

| 场景 | 奖励 | 说明 |
| --- | ---: | --- |
| 新用户注册 | ¥0 | 注册后需要充值才可获得可用额度 |
| 充值 / 月卡 < ¥100 | +¥5 | 支付成功后自动加赠 |
| 充值 / 月卡 >= ¥100 | +¥10 | 支付成功后自动加赠 |

## 对外展示口径

- 注册不直接赠送额度。
- 充值或购买月卡后自动加赠。
- 余额按人民币展示。
- 如遇充值异常，请联系管理员处理。
