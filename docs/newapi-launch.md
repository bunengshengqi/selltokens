# 996 Tokens 上线检查清单

本文件只保留上线检查项，不写内部商业和后台实现细节。

## 域名

```text
www.yourdomain.com   官网和文档
app.yourdomain.com   用户控制台
api.yourdomain.com   API 调用地址
```

## 对外页面

- 首页：品牌、支持模型、Base URL、注册入口。
- 价格页：充值规则、模型单价。
- 文档页：Cursor、Claude Code、OpenAI SDK、curl 示例。
- 状态页：API、控制台、文档、支付服务状态。
- 关于页：产品定位、服务声明、联系方式。

## 首发模型

- `claude-opus-4-7`
- `claude-sonnet-4-6`
- `claude-haiku-4-5`
- `gpt-5.5`
- `gpt-5.4`
- `gpt-5.4-mini`
- `gemini-3.5-flash`

## 充值规则

- 注册不直接赠送额度。
- 账户余额与模型单价按 USD 计费，微信支付按固定汇率折算为人民币。
- 新用户首笔充值后加赠 $1，每个账户仅限一次。
- 充值档位：$3、$5、$10、$20、$50、$100。
- 保留兑换码和人工处理入口，用于异常订单。

## 上线前检查

- [ ] 域名解析完成。
- [ ] HTTPS 证书正常。
- [ ] 登录、注册、充值、API Key、用量记录可用。
- [ ] 首页、价格页、文档页、状态页、关于页不展示内部信息。
- [ ] 首发模型调用测试通过。
- [ ] 支付回调测试通过。
- [ ] 只向海外用户开放的声明已展示。
